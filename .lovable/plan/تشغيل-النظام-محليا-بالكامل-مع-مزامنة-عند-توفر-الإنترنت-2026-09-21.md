# تشغيل النظام محلياً بالكامل مع مزامنة عند توفر الإنترنت

الهدف: يعمل النظام بدون إنترنت نهائياً باستخدام ذاكرة المتصفح، ومع توفر الاتصال تتم مزامنة البيانات تلقائياً حتى يرى الجميع نفس المعلومات.

## كيف سيعمل بعد التنفيذ

- كل الصفحات (الطلاب، الفصول، المخالفات، الإجراءات، المتابعة، التقارير، الإعدادات) تقرأ وتكتب من ذاكرة الجهاز فوراً — بدون انتظار الشبكة.
- عند فتح التطبيق أول مرة على جهاز متصل، تُنسخ البيانات الحالية كاملة إلى الجهاز.
- عند انقطاع الإنترنت يستمر العمل عادياً، وتُحفظ التغييرات في طابور محلي.
- عند عودة الاتصال تُرسل التغييرات تلقائياً وتُجلب تغييرات الآخرين، مع مؤشر في الشريط العلوي: «متصل / غير متصل / جاري المزامنة / عدد التغييرات المعلّقة».
- تسجيل الدخول يبقى ممكناً بدون إنترنت: بعد أول دخول ناجح تُحفظ هوية المستخدم ودوره وصلاحياته محلياً ليُفتح النظام لاحقاً دون اتصال.
- أزرار «تصدير نسخة احتياطية» و«استيراد نسخة» في الإعدادات (ملف واحد يحوي كل البيانات) لنقلها يدوياً بين الأجهزة.

## ملاحظة مهمة

الاحتفاظ بالمزامنة يعني بقاء قاعدة البيانات السحابية كنسخة مشتركة — وهي الوسيلة الوحيدة ليرى المعلمون والمشرفون نفس البيانات. الجديد أن التطبيق لم يعد يعتمد عليها أثناء الاستخدام: كل العمل يجري محلياً أولاً.

## خطة التنفيذ التقنية

1. طبقة بيانات محلية `src/lib/local-db.ts` فوق IndexedDB (عبر `idb`) مع مخازن مطابقة لجداول النظام، وطابور تغييرات `outbox` (جدول، نوع العملية، البيانات، طابع زمني، حالة).
2. واجهة موحدة `src/lib/data.ts` بدوال `list/get/insert/update/remove` لكل كيان تقرأ محلياً وتكتب محلياً ثم تُسجّل في الطابور. كل استعلامات الصفحات تتحول من `supabase.from(...)` إلى هذه الواجهة، مع إبقاء مفاتيح React Query كما هي لتقليل التغيير.
3. محرك مزامنة `src/lib/sync.ts`: سحب أولي كامل، ثم سحب تزايدي بـ `updated_at`/`created_at`، ودفع الطابور بالترتيب، وحل التعارض بقاعدة «الأحدث يفوز» لكل سجل، وإعادة المحاولة عند الفشل، ومستمعات `online/offline`.
4. هوية محلية `src/lib/local-auth.ts`: تخزين الجلسة والدور والصلاحيات في IndexedDB بعد أول دخول؛ عند غياب الاتصال يُسمح بالدخول بنفس اسم المستخدم مقابل بصمة كلمة المرور المخزنة محلياً (SHA-256 عبر Web Crypto). `use-auth.tsx` يعتمد هذا المصدر أولاً ثم يزامن مع السحابة عند الاتصال.
5. مؤشر الحالة: مكوّن `src/components/sync-indicator.tsx` في `app-header.tsx` مع زر «مزامنة الآن».
6. النسخ الاحتياطي: تصدير/استيراد JSON لكل المخازن داخل صفحة الإعدادات (استيراد يستبدل المحلي ثم يُعاد الدفع).
7. تشغيل بدون إنترنت فعلياً: إضافة Service Worker بسيط عبر `vite-plugin-pwa` لتخزين واجهة التطبيق.

## المراحل

- المرحلة 1: الطبقة المحلية + المزامنة + التحويل الكامل للصفحات الأساسية (الطلاب، الفصول، المخالفات، الإجراءات).
- المرحلة 2: المتابعة والتقارير الأكاديمية والسلوكية والإعدادات وسجل التتبع.
- المرحلة 3: الدخول دون اتصال، النسخ الاحتياطي، Service Worker، والتجربة العملية.
