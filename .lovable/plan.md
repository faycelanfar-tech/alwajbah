# تطوير النظام: لوحة تفاعلية، وضع ليلي، إشعارات، سلوك إيجابي

## 1. لوحة تحكم تفاعلية
- **المشرف العام / الإداري**: ثلاثة رسوم بيانية في الصفحة الرئيسية
  - أكثر المخالفات تكراراً (أعمدة أفقية حسب نوع المخالفة)
  - الفصول/الشُعب الأكثر تسجيلاً للمخالفات (أعمدة)
  - التوزيع الزمني للمخالفات (خط زمني: آخر 30 يوماً + عرض شهري للفصل الدراسي)
  - فلتر سريع للفترة: هذا الأسبوع / هذا الشهر / الفصل الدراسي
- **المعلم**: بطاقات مختصرة + جدول "مخالفاتي" يعرض المخالفات التي سجّلها هو فقط مع شارة حالة:
  - قيد المراجعة (بدون إجراء) / تم اتخاذ إجراء / مكتملة
- البطاقات الإحصائية الحالية تبقى، ويتغيّر محتواها حسب الدور.

## 2. الوضع الليلي / النهاري
- زر تبديل في الشريط الجانبي وفي شريط الجوال العلوي.
- حفظ الاختيار في المتصفح، مع خيار "حسب النظام".
- الألوان الداكنة موجودة أصلاً في ملف التصميم؛ سيتم فقط تفعيل التبديل ومراجعة التباين في الجداول والرسوم.

## 3. مركز الإشعارات داخل التطبيق
- أيقونة جرس في أعلى الصفحة مع عدّاد غير المقروء.
- قائمة منسدلة بآخر الإشعارات + وضع علامة "مقروء" وفتح المخالفة مباشرة.
- تحديث لحظي عبر الاشتراك المباشر بقاعدة البيانات.
- المشرف الإداري والمشرف العام يستلمان إشعاراً عند تسجيل مخالفة جديدة، والمعلم يستلم إشعاراً عند اتخاذ إجراء على مخالفته.

## 4. السلوك الإيجابي / البطاقات الخضراء
- قسم جديد "السلوك الإيجابي" في القائمة (للمعلم والمشرف العام).
- تسجيل سلوك متميز: الصف ← الطالب ← نوع السلوك ← الحصة ← ملاحظة، مع نقاط إضافية للطالب والصف.
- أنواع السلوك الإيجابي قابلة للإدارة من الإعدادات (مثل: تعاون، مشاركة متميزة، نظافة، التزام بالواجبات) مع قيمة نقاط لكل نوع.
- ملف الطالب والتقارير يعرضان السلوك الإيجابي بجانب المخالفات (رصيد إيجابي/سلبي).

## 5. سجل العمليات الكامل
- توسيع سجل النشاط ليشمل الحذف والتعديل والسلوك الإيجابي وتغييرات النقاط، مع اسم المنفّذ والتاريخ والقيمة قبل/بعد.
- فلاتر: المستخدم، نوع العملية، الفترة.

## 6. شعار المدرسة
- عرض الشعار واسم المدرسة بشكل واضح في رأس كل صفحة (وليس الشريط الجانبي فقط).
- رأس موحّد في جميع التقارير والطباعة: الشعار + اسم المدرسة + عنوان التقرير + التاريخ.

## التفاصيل التقنية
- جداول جديدة: `positive_behavior_types` (الاسم، النقاط) و`positive_behaviors` (الطالب، النوع، الحصة، الملاحظة، المنفّذ) مع صلاحيات RLS: القراءة للمستخدمين المسجّلين، الإضافة للمعلم/المشرف العام، الحذف للمالك أو المشرف العام، ومُحفِّز لإضافة النقاط للطالب والصف عبر `point_transactions`.
- توسيع مُحفِّزات الإشعارات لإرسال إشعار لكل مستخدم بدور `admin`/`supervisor` عند إدراج مخالفة، وللمعلم صاحب المخالفة عند تحديث الإجراء.
- توسيع `violation_history` لتسجيل الحذف.
- الرسوم البيانية بمكتبة recharts المستخدمة حالياً، والطباعة تعتمد آلية التقاط الرسوم الموجودة.
- مزوّد سمة (theme) في الجذر يضيف صنف `dark` على عنصر html.
- تفعيل realtime لجدول `notifications`.
