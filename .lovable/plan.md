# صلاحية المشرف الإداري للطلاب + بحث شامل في الموقع

## 1. المشرف الإداري يدير الطلاب
حاليًا الإضافة والحذف واللصق الجماعي متاحة للمشرف العام فقط — سواء في الواجهة أو في قاعدة البيانات.

- تعديل قواعد الحماية في قاعدة البيانات: السماح للمشرف الإداري بإضافة وتعديل وحذف الطلاب (يبقى الاطلاع للجميع، وتبقى إدارة الفصول والحسابات للمشرف العام وحده).
- في صفحة «الطلاب»: تظهر للمشرف الإداري أزرار «إضافة طالب» و«لصق طلاب» ومربعات التحديد والحذف الفردي والجماعي، تمامًا كالمشرف العام.

## 2. البحث الشامل
- مربع بحث في الشريط العلوي متاح من كل الصفحات (اختصار لوحة المفاتيح Ctrl/⌘ + K).
- الكتابة تعرض نتائج فورية مصنّفة:
  - الطلاب: الاسم أو رقم الطالب، مع اسم الفصل → فتح بطاقة الطالب.
  - المعلمون والحسابات: الاسم الكامل أو اسم المستخدم، مع صفته → الانتقال لصفحة الحسابات (تظهر فقط لمن يملك صلاحيتها).
  - الفصول: الاسم → صفحة الفصول.
- النتائج تحترم صلاحيات الصفحات: لا يظهر قسم لا يستطيع المستخدم فتحه.
- تحسين البحث داخل صفحة الطلاب ليشمل اسم الفصل أيضًا.

## 3. تحسينات مقترحة (ضمن نفس التنفيذ)
- **تعديل بيانات الطالب**: زر تعديل الاسم/الرقم/الفصل بدل الحذف وإعادة الإضافة، ونقل مجموعة طلاب محددين إلى فصل آخر بضغطة واحدة.
- **حماية من الحذف الخاطئ**: نافذة تأكيد أوضح تعرض عدد المخالفات والسجلات المرتبطة قبل الحذف الجماعي.
- **منع التكرار عند اللصق**: تجاهل الأسماء الموجودة مسبقًا في نفس الفصل مع إظهار عدد المتجاهَل.
- **تصدير قائمة الطلاب** إلى Excel حسب التصفية الحالية.
- **حالة فارغة أوضح** في الجداول مع زر إجراء مباشر بدل عبارة «لا توجد بيانات».
